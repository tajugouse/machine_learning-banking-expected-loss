🧮 MATHEMATICAL FOUNDATION (Summary)
═══════════════════════════════════════════════════════════════════════════════

1. HYPOTHESIS FUNCTION (Linear Regression)
   h(x) = θ₀ + θ₁x₁ + θ₂x₂ + ... + θₙxₙ
   └─ Makes predictions by summing weighted features

2. COST FUNCTION (What We Minimize)
   J(θ) = (1/2m) × Σ(h(xⁱ) - yⁱ)²
   └─ Mean Squared Error (MSE) - strictly convex, no local minima

3. GRADIENT DESCENT (Optimization Algorithm)
   θⱼ := θⱼ - α × ∂J/∂θⱼ
   └─ Update parameters by moving opposite to gradient

4. GRADIENT (Direction of Steepest Descent)
   ∂J/∂θⱼ = (1/m) × Σ(h(xⁱ) - yⁱ) × xⱼⁱ
   └─ Points toward increasing error

5. CONVERGENCE CRITERION (How We Know We're Done)
   Stop when: ||∇J(θ)|| < ε
   Our result: ||∇J|| = 9.27e-07 < ε = 1e-06 ✓ CONVERGED

6. CONVERGENCE THEOREM (Mathematical Guarantee)
   "For strictly convex optimization problems, gradient descent 
    converges to the global minimum."
   └─ MSE is strictly convex → Global minimum guaranteed!

7. EXPECTED LOSS (Basel III Framework)
   EL = PD × LGD × EAD
   └─ PD: Model prediction
   └─ LGD: Loss Given Default (0.45 for unsecured)
   └─ EAD: Exposure At Default (loan amount)
